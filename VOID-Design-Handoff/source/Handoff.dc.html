Engine and build

Inside the playfield frame: rendered by the 2D engine. Outside it: React DOM. The prototype fakes the simulation with fixed paths and a ticking clock.

06World assets

No bitmaps. Every world element is procedural vector drawn from theme tokens, cached per device-pixel-ratio at stage load. Sizes in world units (wu) on a 1150 × 720 field; strokes in screen px. No scanlines or glow inside the playfield except the beacon pulse.

07Playfield contract

  • Engine mounts into data-engine-canvas="playfield". CRT overlay layers sit above the whole screen at lower strength (12%) and never inside the canvas.
  • Phones in portrait use a 360 × 470 wu variant per stage.
  • World labels: SINGULARITY, GATE and the aim readout only. No planet names, no hints.
  • Engine → UI: onTelemetry({ t, fuel, spent, phase, gates }) at 10 Hz; onOutcome({ status, time, fuel, score, cause }).
  • UI → engine: aim, launch, burst(dir), pause, resume, restart, setReducedMotion.
  • Fixed-step physics (120 Hz) so scores are deterministic and replays verifiable. Unchanged from v0.1.

10Config

  • The name renders only from game.name: page titles, wordmark, back links.
